Saranya S — Portfolio

This is my personal portfolio website, built to give recruiters and visitors a quick, clean look at who I am, what I've worked on, and where I'm headed as a developer.

🔗 Live site: saranyas06.netlify.app

About

I'm a final-year B.Tech student in Artificial Intelligence and Data Science, currently working toward a career as a Full Stack / Frontend Developer. This site is where I bring together my projects, certifications, and skills in one place instead of scattering them across a resume and a dozen tabs.

What's on the site
Home – A landing section with a typing animation, a quick intro, and a resume download button
About – A short walkthrough of my background and what I'm working toward
Skills – Frontend, backend, and database/tools I've worked with
Projects – Pulled live from my GitHub via the GitHub REST API, so it stays up to date without me editing HTML every time
Certifications – A gallery of certificates from internships, workshops, and hackathons, viewable in a lightbox
Contact – A working contact form (powered by Formspree) so people can reach out directly
Built with
HTML5, CSS3, JavaScript
Particles.js for the animated background
Typed.js for the typing effect
AOS for scroll animations
Font Awesome for icons
GitHub REST API for pulling in project data
Formspree for handling contact form submissions
Why I built it this way

I wanted something that felt lively without being heavy — no frameworks, no build step, just HTML/CSS/JS that anyone can clone and run straight away. The GitHub API integration for projects was the part I enjoyed most, since it meant I didn't have to manually update the site every time I pushed a new repo.

Running it locally

There's no build process — just clone the repo and open index.html in your browser.

bash
git clone https://github.com/saransrii/portfolio.git
cd portfolio

Then open index.html directly, or serve it with any static server (like the Live Server extension in VS Code).
